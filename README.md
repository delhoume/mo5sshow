# MO5 slideshow

Usage:
1) compile the fdfs.c image builder (from https://github.com/OlivierP-To8/BootFloppyDisk) or from tools/src folder
2) create M5Z images from png or JPEG using png2mo5 from  https://github.com/fstark/png2mo5
3) edit or create a SLIDE.INI to match your images
4) put assets/BOOTMO.BIN assets/MO5SSHOW.BIN, SLIDE.INI and M5Z files in a folder
5) assemble the fd image
``` ../tools/fdfs -addBLFirst mymo5slideshow.fd BOOTMO.BIN MO5SSHOW.BIN SLIDE.INI IMG1.M5Z...IMGN.M5Z```


the resulting fd an be opened in emulators;
- dcmoto (https://dcmoto.pages-perso.free.fr/emulateur/index.html) (choose options/langage/english options/computer/mo5 v1.0 options/external interface/cd90-640) then Removable media/Disks/Load) (works in Mame)

- yame (online https://scemino.github.io/yame_wp/mo5.html) just drop the .fd 
 
Images in the mo5z format generated by png2mo5 are very high quality given the Thomson MO5 graphic constrains.

Or Run `bash build.sh` to build executable and demo disk if you have a running CMOC.
